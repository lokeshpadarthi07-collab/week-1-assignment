# Week 1 Assignment - Full-Stack Portfolio & React Blog

A full-stack web development project containing a **personal portfolio website** and a **React-based blog application**, built with modern frontend and backend technologies.

The project demonstrates frontend development, REST API development, backend integration, deployment, and basic data persistence.



## 🌐 Projects

### 1. 💼 Portfolio Website

A responsive personal portfolio website designed to showcase:

- About Me
- Technical Skills
- Projects
- Contact Information
- Interactive UI
- Contact form with backend integration

**Frontend:** HTML, CSS, JavaScript  
**Backend:** Node.js, Express.js

🔗 **Live Demo:** `https://week-1-assignment-five.vercel.app`

---

### 2. 📝 React Blog Application

A modern blog application built with React and Vite.

#### Features

- View blog posts
- View individual posts
- Comments
- REST API integration
- Responsive React interface
- Persistent JSON-based data

**Frontend:** React, Vite, JavaScript  
**Backend:** Node.js, Express.js

🔗 **Live Demo:** `https://week-1-assignment-ymzx-eight.vercel.app`
